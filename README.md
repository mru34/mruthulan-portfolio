# Mruthulan's portfolio

Personal portfolio for Senthil Nathan Mruthulan at [mruthulan.com](https://mruthulan.com). A static site (HTML, CSS and JavaScript) hosted on GitHub Pages. The pages are generated by one Python script; there is no other build step.

## Design: Night Edition

One dark ground, off-white type. Each kind of text has one face: condensed Archivo capitals for the name, titles and project names; Bricolage Grotesque for big statements (the hero line, leads, award quotes); Geist for reading text and labels; JetBrains Mono only for proof (routes, file names, the stack, figures like S$3,000). Emphasis is weight and gold, never italics. The signature is a split-flap departures board. Titles are gold (#E8B64C; a deeper #8A6400 on the newsprint panel). Project colour appears in small marks, on the project in focus, and on its case page, where the name and the section headings take the project's colour. The colours: SignalBridge teal, MEANT sky blue, Better Call Bhai yellow, KnowCad violet, Boss Breaker orange, Loomy green.

The homepage leads with engineering work: hero, **Featured builds**, **Awards**, **All projects** (with Spin a project beside it), **Press**, **About**, **Let's talk**. Each piece of project information is said once on it: what I built lives only in the featured cards, the awards name the event, placing and project, and the list gives one line per project.

- **Header** is sticky on every page, with Work, Awards, Press and About. On the home page the name, always "Mruthulan Senthil Nathan", is spelled out in flap tiles in the hero (MRUTHULAN in gold, SENTHIL NATHAN in white): a tile flickers under the mouse and lands back on its letter, and a tap ripples the whole name. The small gold "MRUTHULAN" mark slides into the header once the hero has scrolled past. The section being read is underlined in the navigation; hovering a link brightens it and sweeps a gold underline in. On phones there is one navigation: the name and a Menu button (Work, Awards, Press, About, Contact, Résumé). The hero's buttons are See featured work and Résumé.
- **Featured builds** (`#featured`, `FEATURED` in the generator) are SignalBridge, Better Call Bhai and Boss Breaker. Each shows the real product screenshot, what it does, "What I built" as a short list, the stack, and the case study plus the live site or code. The lines are linked hotspots: pointing at a line (or tapping or focusing it) zooms the screenshot to that part with a spotlight, and where there is nothing on screen to show (API routes, tests, database tables) a card opens with the real names from the repository. Every line is backed by the repositories: SignalBridge by my commits to the public repository, Better Call Bhai by its private repository (a solo build), Boss Breaker by its public repository (a solo build). On phones the three builds are a swipe carousel (arrows, dots, a counter), and each build shows its name, then the picture directly above the lines, so a tapped line zooms a picture that is still on screen.
- **Awards** (`#awards`) are one card each: a board strip where the placing flips in letter by letter, with the organisers' logos (Dell InnovateDash, Dell Technologies and Singapore Polytechnic, where it was held; Dell InnovateFest, Dell Technologies; the Autodesk hackathon, Autodesk; the official files in `assets/logos/`, shown in white, linking nowhere); a big photo that swipes on phones and steps with arrows, each opening full size in the viewer; then the event, the project, the opening line of my LinkedIn post about it (`PEEKS`) and the link to the post. On computers the photo alternates sides.
- **All projects** (`#work`) lists five projects, one line each; each row opens its case study, and a case page's "← All work" lands on its row. Beside it (below it on phones), Spin a project is an optional departures board: PROJECT · TYPE · STATUS, flipping to "FIVE PROJECTS" on first view, landing on a random project (never the same one twice in a row) and showing just its name, its line and the case-study link. Loomy, a concept with a pitch deck and no build, is left off the homepage; its case page is reached from the other case pages.
- **Press** is the Tamil Murasu page of 28 September 2026 (page 8), which featured MEANT, on its own newsprint-coloured panel: one line, Read in Tamil, and the page itself, which opens in the full-screen viewer (buttons, wheel, pinch, double-click, drag, arrow keys, Reset, Original, Close; Escape closes and focus returns).
- **About** is a large portrait beside the introduction in big type, then Study and Leadership cards (`#credentials`).
- **Let's talk** (`#contact`) is a full-width band: "Let's talk." in gold, the email address large (a mail link), Copy email address, LinkedIn and the résumé. The footer below is one slim line.
- **Case pages** open with the name at display size, a one-line headline, a short summary, the actions, a facts row (role, result, stack, partner, status) and the lead screenshot. Then a few sections (a handoff flow, a turn, a before and after, a funnel, a loop, research and the pitch deck) and Previous · All work · Next. Role and result are stated once, in the facts row. Where a repository backs it, a "My part" or "In the code" section lists specific contributions as short cards, each with a line saying where the evidence lives: SignalBridge and Boss Breaker from their public repositories, MEANT from the private one (described without code). A thin line at the top shows reading progress.

### Motion

Native scrolling only (in-page links glide to their section). Motion follows the scroll position and never hides content: sections arrive from a softened state, photos drift slightly inside their frames, and the hero name eases away as you scroll past. Moving between the home page and a case page uses cross-document view transitions where the browser supports them: the project name travels into the case title.

The page answers the pointer. Case-page screenshots, the portrait and the Loomy deck tilt toward the mouse with a soft glare; on touch they tilt toward the finger while pressed. Buttons lean a few pixels toward the mouse and fill with colour from the side the pointer came in (outline buttons fill white, solid ones with the project's colour or amber). The newspaper lifts off its panel under the mouse. Flaps on the departures board flicker under the mouse, and section titles and award placings flip in as they arrive.

Smoothness: everything that moves on hover or scroll animates only transform and opacity, which the browser's compositor draws without redoing layout or paint, so motion keeps pace with any screen (60, 120 or 144 Hz) and runs at the same speed on all of them. Pointer effects update at most once per screen frame, however fast the mouse reports, and measure without forcing layout; the tilt writes its transform directly (no inherited custom properties) and slides a pre-drawn glare. Shadows are drawn once and faded in, nothing blurs what is behind it live, and every letter flicker (the name, the board) runs from one frame-synced loop with compositor flap turns. Featured screenshots and award photos are decoded before they are shown. The case-page reading bar is tied to the scroll by CSS where the browser supports it (script otherwise). Measured in headless Chrome with a 4× slower CPU and a 250 Hz mouse, this cut slow frames while hovering a result photo from 45 to 4, page re-layouts under the newspaper magnifier from 800 to 3, and re-layouts while scrolling the page from 306 to 77.

Under `prefers-reduced-motion: reduce` all of this is off (only colour changes remain): the board lands instantly, titles and placings do not spell out, the hotspot view changes without moving, and nothing moves by itself.

### Rules the design depends on

- No stock imagery. Every photo and screenshot is real and captioned; screenshots use fictional or test data.
- Nothing unconfirmed is published. Where wording is not confirmed it is left out rather than guessed.
- The KnowCad repository and the Autodesk materials are private, so that page has no code link and no product screenshots.
- The MEANT repository is linked nowhere.
- The Better Call Bhai testimonial is the owner's own WhatsApp message, emoji removed and one sentence left out, marked with an ellipsis (`data/content.json` records what was cut).
- Loomy's deck is reproduced in full, and its targets and revenue figure are labelled as projections.
- The phone number on the résumé is never published.
- The organisers' logos only name where each event was held: no links, no suggestion of endorsement.
- No visible reading text is smaller than 16px.
- On touch screens every standalone link and button is at least 44px tall.
- The SignalBridge event is "Dell InnovateDash 2026" (the finals signage and the proof post); the SignalBridge page notes that Singapore Polytechnic's feature calls it "SP InnovateDash 2026".

## Editing and rebuilding

All page content lives in `design/build_site.py` (project facts, case-page sections, home page) plus `data/content.json` (the About paragraph and the testimonial) and `data/media.json` (image files, alt text, captions and sizes). Never edit the generated HTML.

```
python design/build_site.py
```

This writes `index.html`, the six case pages, `privacy.html` and `404.html`, makes 800px-wide copies of large images for phones (`*-800.webp`; originals are untouched), and stamps the CSS and JS links. It needs Python 3 and Pillow.

After changing only `css/` or `js/`, run `python design/stamp_assets.py` so browsers fetch the new files instead of a cached copy.

## Preview

Run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Publishing and domain

GitHub Pages publishes the `main` branch from the repository root. The `CNAME` file sets `mruthulan.com` as the custom domain. The Namecheap DNS zone should have GitHub Pages' four apex A records and a `www` CNAME to `mru34.github.io`.

## Analytics

The Google Analytics 4 measurement ID is configured in `js/analytics.js`. The tag loads only after a visitor selects **Allow analytics**; the choice is stored in that browser and can be changed on the privacy page. After consent the site sends `case_open`, `resume_click`, `proof_post_click` (with the project), `spin_result` (the project it landed on), `press_viewer_open`, `press_article_click`, `deck_open`, `contact_copy_email`, `contact_open_mail_app` and `contact_open_linkedin`. No names, email addresses or free text are sent.

## Fonts

Archivo, Bricolage Grotesque, Geist and JetBrains Mono are loaded from Google Fonts (disclosed on the privacy page).
