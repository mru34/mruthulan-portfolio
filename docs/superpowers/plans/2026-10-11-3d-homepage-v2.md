# 3D Homepage v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the homepage as an immersive, full-screen 3D world:

- smooth wheel scrolling and far less of it
- every project, Awards and the ending in 3D, each with its own interaction

**Architecture:**

- **One frame loop:** one ticker runs every frame in a fixed order: Lenis smooth scroll, then the page's beats, then the 3D. The 3D therefore always matches the scroll the page shows.
- **One world:** the scenes stand one after another along a camera path.
  - In the five chapters ("flight sections"), the camera flies along the path, driven by keyframes sampled from the scroll.
  - In the hero, Awards and the ending ("page sections"), the camera holds a fixed pose and fits its 3D into HTML boxes, as in part 1.
- **Scene lifecycle:** each scene is a module that is built when the visitor is near and freed after they leave.

**Tech Stack:**

- three.js 0.186.1 and Lenis 1.3.26, vendored and loaded through an import map
- plain ES modules, no bundler for site code
- Python 3 page generator (`design/build_site.py`)
- Pillow for textures
- node:test for pure logic, pytest, puppeteer-core 23.11.1 for browser checks

**Spec:** `docs/superpowers/specs/2026-10-11-3d-homepage-v2-design.md`. Where it is silent, v1 holds: `docs/superpowers/specs/2026-10-11-3d-homepage-design.md`. Read both before starting.

## Global Constraints

**Never break:**
- Every page arrives finished. Nothing spins, types itself or fades in on load; motion only answers scroll position, pointer or press.
- The page never moves by itself. No snap, no glide after scrolling stops, no auto-advancing photos.
- With reduced motion, Save-Data, no WebGL 2, or less than 4 GB device memory, the visitor gets stills, and Lenis is not started.
- Every screen in the 3D is a real capture or a crop of one, and every photo is real. Nothing is generated. Fixed composites are allowed only where the spec says so.

**Privacy:**
- Never use `d-worker-cockpit.png` or `d-cockpit.png`. The supervisor capture is used only cropped above its "Signed in as" corner.
- The phone number is never published. Raw captures in `../portfolio-tools/card-shots/raw` are never copied into the repository; only derived WebP files in `assets/3d/` are.

**Git:**
- Commits are credited to Mruthulan only: no `Co-Authored-By`, no Claude authorship.
- Do not push or open a pull request until Mruthulan asks.

**How the site is built:**
- Never edit generated HTML (`index.html` and the case pages). Edit `design/build_site.py`, then run `python design/build_site.py`.
- Libraries are pinned exactly: `three@0.186.1`, `lenis@1.3.26`, `esbuild@0.28.2`, `puppeteer-core@23.11.1`.

**Copy:**
- No visible reading text under 16px. On touch screens every link and button is at least 44px tall.
- Every word on the homepage is in v1's copy deck, as changed by the v2 spec ("Words changed from v1's copy deck").
- Writing rules and the banned words from v1 apply.

**Look:**
- No full-screen post-processing (bloom passes, lens flares), no neon outlines, no rainbow or purple-blue gradients, no random floating shapes.
- No new three.js lights after start. The set of lights is fixed, so shaders never recompile mid-scroll.

**Budgets:**
- Three.js, Lenis and the site's own 3D code: ≤ 320 KB gzipped.
- Each chapter's textures: ≤ 600 KB.

**Pacing:**
- Laptop (1440×900): at most 12 screens of scrolling (`scrollHeight − innerHeight ≤ 12 × innerHeight`).
- SignalBridge's result is fully shown within 2.5 screens of the top.

**Smoothness:**
- Slow frames (over 33 ms) stay under 5% with the CPU slowed 4×, on desktop and phone (or the phone ends on stills).
- The camera uses the page's scroll value in every frame.
- In page sections at rest, a fitted object is within 1 px of its HTML box.

## Review Focus

These are the inputs the spec implies that are most likely to bite a real visitor. Each one has a test in the task named after it.

1. **Resizing or rotating the window in the middle of a chapter:** the camera keeps to the same place in the story, and nothing errors or stays half-built. *(Task 3: smoke "resizing mid-chapter keeps the camera on the path")*
2. **Jumping the whole page at once** (End then Home, or dragging the scrollbar): scenes are built and freed in bursts without errors, and GPU memory returns to where it started. *(Task 3: smoke "End then Home frees what it built")*
3. **Clicking an in-page link** (header Work, Awards, Contact) while Lenis is gliding: the page lands exactly where the link points, and Lenis doesn't drag it away afterwards. *(Task 1: smoke "a header link glides and lands exactly")*
4. **Using the mouse wheel inside the full-screen photo viewer:** it zooms the photo and never scrolls the page behind. *(Task 1: smoke "the wheel inside the viewer never scrolls the page")*
5. **A vertical swipe on a phone that starts on something you can touch** (a barber pole, an Awards print, the KnowCad sheets): it still scrolls the page. *(Task 9: smoke "a vertical swipe on a print or pole still scrolls")*

**Shared vocabulary** (every task uses these names):

- **Screen time `s`:** `scrollY / innerHeight`.
- **Chapter base `T_i`:** chapter *i*'s `offsetTop / innerHeight`. Chapter-local time is `local = s − T_i`:
  - −1 means the chapter is just entering from below
  - 0 means its pin has started
  - 0.6 means its pin ends
  - 1.6 means it has gone
- **Keys:** objects `{ t, at:[x,y,z], from:[x,y,z], w, h }` or `{ t, at, from, d }`, plus optional `stop: true` and `color: [r,g,b]` (0–1).
  - `t` is chapter-local in `paths.js`; world converts it to screen time.
  - Every flight scene has keys at local −0.4 (arriving), 0.42 (`stop`, payoff), 0.6 (`stop`, hold) and 0.9 (leaving).
- **Beats:** `line` = ramp(p, 0.05, 0.3), `pay` = ramp(p, 0.45, 0.7), where `p` is pinned progress (0..1 over the 0.6 screen pin). The key pose is p = 0.8, which is local 0.48.

- [ ] **Step 3: Write `js/lib/ticker.js`:**

```js
// One animation loop for the whole homepage. Each frame runs its jobs in the order they were added (smooth
// scroll, then the page's beats, then the 3D), so everything drawn in a frame agrees on the scroll position.
// It sleeps when no job is busy and wakes on invalidate(), so nothing moves by itself.
export function createTicker(raf = (fn) => requestAnimationFrame(fn), caf = (id) => cancelAnimationFrame(id)) {
  const jobs = [];
  let id = 0;
  let last = 0;     // for springs: reset when the loop sleeps, so a pause is never one huge step
  let prev = 0;     // for the watchdog: never reset, so it sees how long frames really take
  let stopped = false;
  function frame(now) {
    id = 0;
    const dt = last ? Math.min(now - last, 100) : 16;
    const gap = prev ? now - prev : 0;
    last = now;
    prev = now;
    let busy = false;
    for (const job of [...jobs]) busy = job(now, dt, gap > 0 && gap < 500 ? gap : null) || busy;
    if (busy) invalidate(); else last = 0;
  }
  function invalidate() { if (!id && !stopped) id = raf(frame); }
  return {
    add(job) { jobs.push(job); invalidate(); return () => { const i = jobs.indexOf(job); if (i >= 0) jobs.splice(i, 1); }; },
    invalidate,
    stop() { stopped = true; if (id) caf(id); id = 0; },
    get running() { return Boolean(id); },
  };
}
```

```js
export const KEY = 0.8;
export const BEATS = { line: [0.05, 0.3], pay: [0.45, 0.7] };
const params = new URLSearchParams(location.search);

// layout read once per resize, so no frame reads layout: each chapter's top, height and pin height
let lay = [];
function measure() {
  lay = chapters.map((c) => ({ top: c.offsetTop, h: c.offsetHeight, pin: c.querySelector('.pin').offsetHeight }));
}
function beats(y) {
  const vh = innerHeight;
  lay.forEach((L, i) => {
    const top = L.top - y;
    if (top + L.h < -vh || top > 2 * vh) return;
    const p = sectionProgress(top, L.h, L.pin);
    chapters[i].style.setProperty('--b1', ramp(p, ...BEATS.line).toFixed(3));
    chapters[i].style.setProperty('--b2', ramp(p, ...BEATS.pay).toFixed(3));
  });
  const now = currentChapter(lay.map((L) => ({ top: L.top - y, bottom: L.top - y + L.h })), vh);
  if (rail) { rail.classList.toggle('on', now >= 0); marks.forEach((m, k) => m.toggleAttribute('data-on', k === now)); }
}

if (live) {
  const ticker = createTicker();
  let lenis = null;
  if (params.get('smooth') !== 'off' && !pose) {
    const { default: Lenis } = await import('lenis');
    lenis = new Lenis({ autoRaf: false, lerp: 0.1, smoothWheel: true, syncTouch: false, anchors: false,
      prevent: (node) => Boolean(node.closest('dialog[open], [data-lenis-prevent]')) });
    root.classList.add('smooth');

    window.__lenis = lenis;   // the smoke tests read isScrolling

  addEventListener('resize', () => { measure(); ticker.invalidate(); });

  // in-page links glide with Lenis and land exactly where the browser would have put them
  if (lenis) document.addEventListener('click', (e) => {
    const a = e.target.closest('a[href^="#"], a[href^="index.html#"]');
    if (!a || e.defaultPrevented || e.button || e.metaKey || e.ctrlKey || e.shiftKey) return;
    const target = document.getElementById(decodeURIComponent(a.hash.slice(1)));
    if (!target) return;
```

```js
// The camera's path through the world, as keyframes: a point to look at, the direction the camera looks from,
// and either a distance or an area (w x h) to frame, which turns into a distance for the screen's shape. Between
// keys every number moves along a cubic Hermite curve with tangents from the neighbouring keys, so the camera
// never jerks at a key; a key marked stop is arrived at and left at zero speed (a hold). Pure, so it is tested.
import { clamp } from './motion.js';

export const FRAME_K = 2 * Math.tan((30 * Math.PI) / 360);   // the stage's 30° vertical field of view

export function frameDistance(w, h, aspect, k = FRAME_K) {
  return Math.max(h, w / aspect) / k;
}

const norm = (v) => { const l = Math.hypot(v[0], v[1], v[2]) || 1; return [v[0] / l, v[1] / l, v[2] / l]; };
const smooth = (u) => u * u * (3 - 2 * u);
// a key as plain numbers: look-at point (3), direction toward the camera (3, unit), distance (1)
const flat = (k, aspect) => [...k.at, ...norm(k.from), k.d ?? frameDistance(k.w, k.h, aspect)];

export function sampleKeys(keys, t, aspect) {
  const n = keys.length;
  const pack = (v, color) => ({ at: v.slice(0, 3), from: norm(v.slice(3, 6)), d: v[6], color });
  if (t <= keys[0].t) return pack(flat(keys[0], aspect), keys[0].color);
  if (t >= keys[n - 1].t) return pack(flat(keys[n - 1], aspect), keys[n - 1].color);
  let k = 0;
  while (keys[k + 1].t <= t) k++;
  const a = keys[k], b = keys[k + 1];
  const h = b.t - a.t;
  const u = (t - a.t) / h;
  const va = flat(a, aspect), vb = flat(b, aspect);
  const tangent = (i) => {
    if (keys[i].stop || i === 0 || i === n - 1) return [0, 0, 0, 0, 0, 0, 0];
    const p = flat(keys[i - 1], aspect), q = flat(keys[i + 1], aspect);
    const span = keys[i + 1].t - keys[i - 1].t;
    return q.map((x, j) => (x - p[j]) / span);
  };
  const ma = tangent(k), mb = tangent(k + 1);
  const u2 = u * u, u3 = u2 * u;
  const h00 = 2 * u3 - 3 * u2 + 1, h10 = u3 - 2 * u2 + u, h01 = -2 * u3 + 3 * u2, h11 = u3 - u2;
  const v = va.map((x, j) => h00 * x + h10 * h * ma[j] + h01 * vb[j] + h11 * h * mb[j]);
  const s = smooth(u);
  const color = a.color && b.color ? a.color.map((c, j) => c + (b.color[j] - c) * s) : (a.color || b.color);
  return pack(v, color);
}

// how much the camera should behave like the page (fixed pose, no pointer look): 1 at the top until the hero
// starts leaving, 0 through the chapters, rising to 1 as the page sections (Awards on) arrive
export function pageWeight(s, heroEnd, pageStart) {
  const top = 1 - clamp(s / heroEnd);
  const end = clamp((s - (pageStart - 0.3)) / 0.3);
  return Math.max(top, end);
}
```

```js
// Seeded randomness, so a scene is laid out the same way every visit (and in its still).
export function mulberry32(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

// n points in a box, none closer than `corridor` to the line x = 0, y = 0 (where a camera flies)
export function scatter(n, seed, box, corridor = 0) {
  const r = mulberry32(seed);
  const pick = ([a, b]) => a + (b - a) * r();
  const out = [];
  while (out.length < n) {
    const p = [pick(box.x), pick(box.y), pick(box.z)];
    if (Math.hypot(p[0], p[1]) >= corridor) out.push(p);
  }
  return out;
}
```

```js
  root.traverse((o) => {

    if (o.geometry) o.geometry.dispose();
```

```js
// The homepage's one 3D world. Scenes stand one after another along the camera's path (js/3d/paths.js): the
// hero board, the five chapters, then the Awards table and the ending board. The scroll position picks the
// camera's pose from the keys, so moving between projects is a camera flight. In the page sections (the hero
// at rest, Awards, the ending) the camera holds the page pose, so 3D fitted to HTML boxes lines up exactly.
// The lights travel with the camera and take each project's colour; there are always the same four, so
// shaders never recompile mid-scroll. Scenes are built when the visitor is within one section and freed three
// sections away.
import * as THREE from 'three';
import { sampleKeys, pageWeight } from '../lib/path.js';
import { Spring, clamp } from '../lib/motion.js';
import { rectToWorld } from '../lib/fit.js';
import { CAM_Z } from './stage.js';
import { KEYS, ORIGINS, COLORS } from './paths.js';
import { disposeTree } from './textures.js';

const BG = 0x0c0c0d;

export function createWorld(stage, { sections, form }) {
  const { scene, camera, renderer, view } = stage;
  const root = new THREE.Group();
  scene.add(root);
  scene.fog = new THREE.Fog(BG, 30, 60);
  renderer.localClippingEnabled = true;   // Better Call Bhai's phone slides its screens inside the screen's edges

  // the rig: key from the top left, a dim fill, a coloured rim from behind and a coloured bounce from below,
  // all placed in the camera's own space
  const rig = new THREE.Group();
  const light = (color, i, pos, aim) => {
    const l = new THREE.DirectionalLight(color, i); l.position.set(...pos);
    l.target.position.set(...aim); rig.add(l, l.target); return l;
  };
  light(0xffffff, 1.4, [-6, 8, 4], [0, 0, -10]);
  light(0xc8d2ff, 0.25, [6, -3, 4], [0, 0, -10]);
  const rim = light(0xffffff, 1.6, [5, 5, -22], [0, 0, -8]);
  const bounce = light(0xffffff, 0.35, [0, -6, -4], [0, 0, -10]);
  scene.add(rig);

  const v3 = (a) => new THREE.Vector3(...a);
  const origins = Object.fromEntries(Object.entries(ORIGINS).map(([k, a]) => [k, v3(a)]));
  const mounted = new Map();     // name -> part
  const pending = new Map();     // name -> promise
  const docRects = new Map();    // element -> { left, top, width, height } in document coordinates
  let keys = [], bases = {}, heroEnd = 0.4, pageStart = 99, vh = 1, aspect = 1;
  let lastScroll = 0;
  const lookX = new Spring(0, { stiffness: 60, damping: 16 });
  const lookY = new Spring(0, { stiffness: 60, damping: 16 });
  const shakeS = new Spring(0, { stiffness: 900, damping: 18 });

  const fitted = () => sections.filter((s) => s.kind === 'page').flatMap((s) => [...s.el.querySelectorAll('[data-anchor]')]);
  function layout() {
    vh = innerHeight; aspect = innerWidth / innerHeight;
    for (const el of fitted()) {
      const r = el.getBoundingClientRect();
      docRects.set(el, { left: r.left + scrollX, top: r.top + scrollY, width: r.width, height: r.height });
    }
    bases = Object.fromEntries(sections.map((s) => [s.name, s.el.offsetTop / vh]));
    const pageEl = sections.find((s) => s.name === 'awards')?.el;
    pageStart = pageEl ? pageEl.offsetTop / vh - 0.6 : 99;
    const pagePose = (t) => ({ t, at: [...ORIGINS.page], from: [0, 0, 1], d: CAM_Z, stop: true, color: COLORS.page });
    keys = [{ t: 0, at: [...ORIGINS.hero], from: [0, 0, 1], d: CAM_Z, stop: true, color: COLORS.hero }];
    for (const s of sections) {
      if (s.kind !== 'flight') continue;
      const o = ORIGINS[s.name];
      for (const k of KEYS[s.name]) {
        keys.push({ ...k, t: bases[s.name] + k.t, at: [k.at[0] + o[0], k.at[1] + o[1], k.at[2] + o[2]], color: COLORS[s.name] });
      }
    }
    keys.push(pagePose(pageStart), pagePose(pageStart + 100));
    heroEnd = 0.4;
  }

  function boxToWorld(el, originName) {
    const d = docRects.get(el);
    const o = origins[originName];
    if (!d) return { x: o.x, y: o.y, w: 0, h: 0, z: o.z };
    const r = rectToWorld({ left: d.left - scrollX, top: d.top - scrollY, width: d.width, height: d.height }, view.w, view.h, view.k);
    return { x: r.x + o.x, y: r.y + o.y, w: r.w, h: r.h, z: o.z };
  }

  const current = (y) => {
    const mid = y + vh / 2;
    let i = sections.findIndex((s) => s.el.offsetTop <= mid && s.el.offsetTop + s.el.offsetHeight > mid);
    if (i < 0) i = mid < sections[0].el.offsetTop ? 0 : sections.length - 1;
    return i;
  };

  async function mountScene(s) {
    if (mounted.has(s.name) || pending.has(s.name)) return pending.get(s.name);
    const job = (async () => {
      const mod = await s.load();
      const part = await mod.mount({ THREE, world: api, stage, section: s.el, form, origin: origins[s.name] ?? origins.page, invalidate: stage.invalidate });
      if (!pending.has(s.name)) { part.dispose(); return; }   // freed while it was loading
      mounted.set(s.name, part);
      s.el.setAttribute('data-live', '');
      stage.invalidate();
    })().catch((err) => { console.warn(`3D scene "${s.name}" did not load; its still stays.`, err); s.el.setAttribute('data-failed', ''); })
      .finally(() => pending.delete(s.name));
    pending.set(s.name, job);
    return job;
  }
  function free(s) {
    pending.delete(s.name);
    const part = mounted.get(s.name);
    if (!part) return;
    part.dispose();
    mounted.delete(s.name);
    s.el.removeAttribute('data-live');
  }

  const camPos = new THREE.Vector3(), camAt = new THREE.Vector3();
  const api = {
    root, rig, mounted, layout, boxToWorld,
    get lastScroll() { return lastScroll; },
    origin: (name) => origins[name].clone(),
    shake(a) { shakeS.velocity += a; stage.invalidate(); },
    ray(clientX, clientY) {
      const r = new THREE.Raycaster();
      r.setFromCamera(new THREE.Vector2((clientX / view.w) * 2 - 1, -(clientY / view.h) * 2 + 1), camera);
      return r;
    },
    counts: () => ({ ...renderer.info.memory }),
    async pose(name) {
      const s = sections.find((x) => x.name === name);
      await mountScene(s);
      return s;
    },
    update(now, dt) {
      const y = scrollY;
      lastScroll = y;
      const s = y / vh;
      // the scenes near the visitor exist; far ones are freed
      const cur = current(y);
      sections.forEach((sec, i) => {
        if (Math.abs(i - cur) <= 1) mountScene(sec);
        else if (Math.abs(i - cur) >= 3) free(sec);
      });
      // the camera
      const k = sampleKeys(keys, s, aspect);
      camAt.set(...k.at);
      camPos.set(...k.from).multiplyScalar(k.d).add(camAt);
      const pw = pageWeight(s, heroEnd, pageStart);
      const P = stage.pointer;
      const mouse = P.inside && P.type === 'mouse';
      lookX.target = mouse ? P.nx * 0.045 * (1 - pw) : 0;
      lookY.target = mouse ? P.ny * 0.03 * (1 - pw) : 0;
      let busy = lookX.step(dt);
      busy = lookY.step(dt) || busy;
      busy = shakeS.step(dt) || busy;
      camera.position.copy(camPos);
      camera.position.x += shakeS.value * 0.04;
      camera.position.y += shakeS.value * 0.025;
      camera.lookAt(camAt);
      camera.rotateY(-lookX.value);
      camera.rotateX(lookY.value);
      scene.fog.near = k.d * 1.4 + 2;
      scene.fog.far = scene.fog.near + 28;
      // the rig follows the camera and takes the colour of where the camera is
      rig.position.copy(camera.position);
      rig.quaternion.copy(camera.quaternion);
      rim.color.setRGB(...k.color);
      bounce.color.setRGB(...k.color);
      // each mounted scene poses itself; flight scenes get their chapter-local time
      const f = { now, dt, s, vh, pointer: P, camera, form, pageWeight: pw };
      for (const sec of sections) {
        const part = mounted.get(sec.name);
        if (!part) continue;
        busy = part.update(sec.kind === 'flight' ? s - bases[sec.name] : null, f) || busy;
      }
      return busy;
    },
  };
  layout();
  addEventListener('resize', () => { layout(); stage.invalidate(); });
  new ResizeObserver(() => { layout(); stage.invalidate(); }).observe(document.querySelector('main'));
  return api;
}
```

```js
// Two small pieces of physics, in units per second: a spin that slows down under drag (the barber pole) and a
// slide with friction that also turns (a flicked print). dt in milliseconds. Pure, so they are tested.
const REST = 0.02;

export function spinStep({ angle, vel }, dt, { drag = 1.6 } = {}) {
  const s = Math.min(dt, 64) / 1000;
  const v = vel * Math.exp(-drag * s);
  const resting = Math.abs(v) < REST;
  return { angle: angle + (resting ? 0 : v * s), vel: resting ? 0 : v, resting };
}

export function flickStep({ x, y, vx, vy, rot, vr }, dt, { friction = 3.2 } = {}) {
  const s = Math.min(dt, 64) / 1000;
  const k = Math.exp(-friction * s);
  const nvx = vx * k, nvy = vy * k, nvr = vr * k;
  const resting = Math.hypot(nvx, nvy) < REST && Math.abs(nvr) < REST;
  return resting
    ? { x, y, vx: 0, vy: 0, rot, vr: 0, resting }
    : { x: x + nvx * s, y: y + nvy * s, vx: nvx, vy: nvy, rot: rot + nvr * s, vr: nvr, resting };
}
```

```js
// flown from the phone onto the wall.
import { ramp, easeInOut } from '../../lib/motion.js';
// screen k is reached at CUTS[k]; each change slides over 0.05 of a screen of scrolling
const CUTS = [-1, 0.03, 0.14, 0.3];
export function bbScreen(local) {
  for (let k = CUTS.length - 1; k > 0; k--) {
    if (local >= CUTS[k] + 0.05) return { from: k, to: k, t: 1 };
    if (local >= CUTS[k]) return { from: k - 1, to: k, t: easeInOut((local - CUTS[k]) / 0.05) };

  return { from: 0, to: 0, t: 1 };
}
```

```js
export const GLYPHS = ' ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789/.·-';

// what a tile shows when a scroll position x (0..1) is scrubbing it through `seq`: scrolling back turns it back
export function scrubState(seq, x) {
  const turns = seq.length - 1;
  if (x <= 0 || turns <= 0) return { from: seq[0], to: seq[0], t: 1, done: true };
  if (x >= 1) return { from: seq[turns], to: seq[turns], t: 1, done: true };
  const pos = x * turns, k = Math.floor(pos);
  return { from: seq[k], to: seq[k + 1], t: pos - k, done: false };
}

// a blank, then `steps` letters from a seeded flicker, then the letter: the same for the same seed
export function scrubSeq(final, steps, seed) {
  return [' ', ...flickerSequence(final, steps, mulberry32(seed)).slice(1)];
}
```
