Portfolio V2 — two directions

Two live, interactive mockups built from the real project facts and copy limits in the brief — geometric placeholders only, no images. Open each on desktop and resize to phone width to get a feel for both. Pick one, mix elements, or send notes and I'll refine before building the full clickable 3D prototype.

Direction A — Recommended

Signal Lab

Near-black, sharp and experimental. One electric accent, one warm accent. Oversized type, a faint CSS grid + grain, and a five-module node graph standing in for the eventual 3D hero scene.

Interaction intent

Click a project button (or a node) to see the connected module light up and the proof panel update — a preview of how the real 3D scene will respond to the same selection state. Everything here already works by mouse, touch and keyboard.

Open Signal Lab ↗
Direction B — Comparison

Kinetic Type

Paper-toned, editorial and typographic. Hard rules, a scrolling fact marquee, and a stacked-card project switcher built entirely from CSS depth — no 3D at all.

Interaction intent

Selecting a project name in the list promotes its stacked card to the front with a short cross-fade and updates the fact line beneath the list. Faster to build and the most robust fallback if the 3D scene proves too heavy on weaker devices.
