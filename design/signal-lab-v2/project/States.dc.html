Reduced motion

Every animation sits inside prefers-reduced-motion: no-preference, so the default for a user who asks for less motion is this — one composed, static frame. Selection still changes shape, lighting and copy; it just cross-fades instead of travelling.

Stops: drift, travelling pulse, glow breathing, cube rotation, weave slide

No JavaScript · no WebGL

This direction never needs WebGL — the forms are inline SVG and CSS layers, so there is no 3D cliff to fall off. With scripting off the page still ships the full project index in HTML, each row a link with its own colour mark and outcome.
