01 / The problem

Support should carry context forward.

Youth workers pick up conversations that started somewhere else — a late-night message, a different volunteer, a different week. The context rarely travels with the person.

SignalBridge makes the next handoff clearer while keeping the final judgement with the worker, not the model.

02 / The product

One place for a careful handoff.

Conversations, risk signals and consent-led briefs sit in one view. AI drafts the summary; the worker edits, approves or discards it before anything moves on.

03 / My contribution

From interface to integration.

I built the youth-facing flow, the API and Discord integrations, and the automated tests that kept the handoff logic honest as the team moved fast.
