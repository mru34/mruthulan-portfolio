How I work

  1. Start with one person. I built SignalBridge’s consent screen: a youth’s note reaches their worker only after the youth has read it and said yes.
  2. Make the demo hard to break. Before MEANT’s live demo I fixed a stuck mic, a silent send and a black camera.
  3. Keep the rules on the server. In Boss Breaker the server works out points and boss damage, so the browser can’t cheat.
  4. Then explain it. I built and delivered the winning presentation at the Autodesk Singapore Hackathon 2026.
